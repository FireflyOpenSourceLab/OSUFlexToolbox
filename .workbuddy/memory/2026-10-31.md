## osu! 启动器（标题栏右端）

跨进程三层：`src/main/osu.ts`（探测+启动）→ `src/preload`（`window.api.osu`）→
`src/renderer/src/components/osu-launcher.tsx`（Select + Play）。
类型抽到 `src/shared/osu.ts` 供 main/preload/renderer 共用，避免漂移；
tsconfig.web.json 的 include 需补 `src/shared/*.ts`（否则 web 程序看不到）。

**探测路径**（用户要求：Windows 探 lazer+stable 都显示；macOS 只探 lazer）：
- Win lazer：`%LOCALAPPDATA%\osulazer\osu!.exe` 与 `...\osulazer\current\osu!.exe`（两种布局都试）
- Win stable：① `HKCR\osu!\shell\open\command`（自定义安装位置时唯一可靠来源）
  ② `HKCU\...\Uninstall\osu!` 的 InstallLocation ③ 兜底 `%LOCALAPPDATA%\osu!\osu!.exe`
- macOS lazer：`/Applications/osu!.app` 与 `~/Applications/osu!.app`（本机实测**前者存在**）
- Linux：不探测，返回空。启动用 `shell.openPath()`（.exe 与 .app 通用）

**布局（按平台分支）**：`.app-header` 右侧留白随平台变，`data-platform` 由 `main.tsx`
用 `window.electron.process.platform` 写在 `<html>` 上（`@electron-toolkit/preload` 的
`electronAPI.process` 含 platform）：
```css
.app-header { padding-left: max(12px, env(titlebar-area-x, 12px)); padding-right: 12px; }
[data-platform='win32'] .app-header, [data-platform='linux'] .app-header {
  padding-right: calc(100vw - env(titlebar-area-width, 100vw));
}
```
**踩过的坑**：原来三平台统一用 `padding-right: calc(100vw - env(titlebar-area-width))`，
但 macOS 上 `titlebar-area-x + titlebar-area-width = 100vw`（红绿灯占左侧），
该式等于红绿灯宽度（实测 84px），导致右端控件顶不到最右。macOS 右端无遮挡，应留 12px。
左侧用 `max(12px, …)` 是因为 Windows 上 `titlebar-area-x = 0`，直接用 env 会让控件贴死左边缘。
标题栏仅 40px 高，Select 用 `size="sm"` + `h-7`。

**lint 现状**：全量 365 个问题（66 error），几乎都在 shadcn CLI 生成文件（双引号 vs prettier
单引号），是既有问题非本次引入。手写文件保持 0 error。

## react-router 路由

**必须用 `HashRouter`**：生产走 `loadFile`（`file://` 协议），`BrowserRouter` 无服务端回退会 404；
dev 的 `ELECTRON_RENDERER_URL` 是 http，用 Browser 能跑但 prod 会炸，故统一 Hash。

路径刻意用 NavKey 作段名，互转一行搞定、无需映射表：
```ts
const pathOf = (key: NavKey) => (key === 'home' ? '/' : `/${key}`)
const keyOf = (path: string): NavKey => {
  const seg = path.replace(/^\//, '')
  return seg && seg in PAGE_TITLES ? (seg as NavKey) : 'home'
}
```
路由：`/` home、`/skins` skin、`/beatmaps` bm、`/resources` source、`/settings` settings，
`path="*"` 一律 `<Navigate to="/" replace />` 回落 home。

## 跨平台隐藏标题栏 → 改用 Chromium WCO

`src/main/index.ts`：
```ts
const TITLE_BAR_HEIGHT = 40
titleBarStyle: 'hidden',
titleBarOverlay: { height: TITLE_BAR_HEIGHT },        // 三平台统一开启
...(process.platform === 'darwin' ? { trafficLightPosition: { x: 12, y: 12 } } : {})
```
**关键**：`titleBarOverlay` 不是只给 Windows 用的——在 macOS 上它正是启用 WCO
（JS API + `titlebar-area-*` CSS 环境变量）的开关。之前只对非 darwin 设置，
导致 macOS 拿不到这些变量。

renderer `globals.css` 用官方推荐的安全区写法（无需按平台写死宽度）：
```css
.app-header {
  height: env(titlebar-area-height, 40px);
  padding-left: env(titlebar-area-x, 12px);                          /* macOS 红绿灯 */
  padding-right: calc(100vw - env(titlebar-area-width, 100vw));      /* Win/Linux 三大件 */
  -webkit-app-region: drag;
}
.app-header button, .app-header input, .app-header a,
.app-header [data-slot], .no-drag { -webkit-app-region: no-drag; }
```
- macOS 全屏时红绿灯移入系统菜单栏，`titlebar-area-x` 自动归零，无需 JS 监听
- `color`/`symbolColor` 仅 Windows/Linux 生效；不传即跟随系统配色
- `trafficLightPosition` 仅 macOS，控制红绿灯上/左边距
- 标题栏内可交互元素必须 `no-drag`，否则点不动

## 环境坑（本机沙箱）

- **`ELECTRON_RUN_AS_NODE=1` 被注入到 shell 环境** → Electron 以纯 Node 运行，
  `require('electron')` 只返回二进制路径，报 `Cannot read properties of undefined (reading 'isPackaged')`。
  解决：`env -u ELECTRON_RUN_AS_NODE npm run start`。`electron --version` 打印 Node 版本（如 v24.x）即此症状。
- **`--ignore-scripts` 会跳过 `postinstall`（`install-electron`）** → Electron 二进制缺失。
  补救：`./node_modules/.bin/install-electron`。
- **`vite:prepare-out-dir` 的 `emptyDir` 被安全删除 shim 拦截**
  （`SAFE_DELETE_BULK_GUARD_ERROR: state lock timeout`）。解决：config 里设 `build.emptyOutDir: false`。
- 嵌套沙箱下 Chromium `sandbox initialization failed`，需 `--no-sandbox` 才能起窗口；
  `screencapture` 被禁用（`could not create image from display`），无法截图。
